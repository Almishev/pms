# Hotel PMS Frontend

React.js frontend for Hotel Property Management System.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

The app will be available at http://localhost:3000

## Features

- User authentication (JWT)
- Room management
- Booking management
- Payment processing
- Reports (Occupancy, Nights, Revenue)
- Role-based access control

## Default Credentials

- Admin: `admin` / `admin123`
- Receptionist: `receptionist` / `admin123`
